# barotable-pagetest

바로테이블 화면 설계를 같이 보기 위한 버전입니다. 백엔드 없이, 데이터는 모두 하드코딩돼 있습니다.

## 여는 방법
`src/main/resources/templates/index.html`을 브라우저로 열면 됩니다.
(입력값이 화면 사이에 안 이어지면 `src/main/resources`에서 `python -m http.server` 실행 후
`http://localhost:8000/templates/index.html`로 접속)

## 동작하는 것
1. **AI 채팅 팝업 (좌석 선택 화면):** 문장에서 날짜·시간·인원·요청사항을 정리하고, 확인하면 좌석도 조건에 적용합니다. (서버 없이 규칙으로 흉내. 실제 서비스의 AI 기본값은 로컬 LLM)
2. **층별 구역:** 손님 화면 층 탭·구역 필터, 점주 좌석도 편집에서 층 추가·이름 변경·삭제와 구역 추가·이동·크기 조절·이름/색 변경·삭제
3. **날짜·시간 선택:** 2026년 10월만, 11:30–21:30 (30분 단위, 브레이크 15:00–17:00 선택 불가)
4. **화면 이동:** 버튼과 상단 PAGE TEST 바의 화면 목록
5. **비회원 조회·취소 (C-07):** 예약번호와 연락처가 모두 맞아야 조회되고, 예약 시간 전의 확정 예약만 취소됩니다.
6. **점주 대시보드 (O-02):** 상태 필터, 예약 선택, 방문 완료, 노쇼 처리·되돌리기, 테이블 옮기기, 워크인 배정. 기준 시각은 10월 5일 19:00으로 고정입니다.

5·6에서 바꾼 내용은 브라우저 탭의 sessionStorage에 저장돼 같은 탭에서 화면을 옮겨도 이어집니다. 대시보드의 "시연 데이터 초기화"로 되돌릴 수 있습니다.
그 밖의 버튼과 값은 화면 모양만 보여 주는 고정 상태입니다.
